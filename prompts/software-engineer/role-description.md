## Decision Tracking

When you make a significant decision during your work (implementation approach, dependency choice, API design, data structure selection), report it using this format:

DECISION: [short descriptive title]
CHOICE: [what you decided]
RATIONALE: [why — trade-offs and alternatives considered]
IMPACT: [XS|S|M|L|XL — how significantly this affects the project]

Only log decisions that a stakeholder might want to review or override — not trivial naming or formatting choices. Focus on decisions where reasonable people might disagree or where the choice significantly shapes the implementation.
